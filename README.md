# 🚕 OLA Booking Analysis – SQL & Power BI

## 📌 Project Overview

This project analyzes OLA ride booking data to identify booking trends,
cancellation patterns, customer behavior, vehicle performance, and revenue insights.

The project uses SQL for data analysis and Power BI to create an interactive dashboard.

## 📊 Dataset

- Total Records: 40,539
- Total Columns: 20
- Data Period: July 2024
- Domain: Ride Booking / Transportation

## 🛠️ Tools & Technologies

- SQL
- MySQL
- Power BI
- Excel / CSV

## 🔍 SQL Analysis

The following business questions were analyzed using SQL:

1. Retrieve all successful bookings.
2. Find the average ride distance for each vehicle type.
3. Get the total number of rides cancelled by customers.
4. Identify the top 5 customers with the highest number of bookings.
5. Find the number of rides cancelled by drivers due to personal and car-related issues.
6. Find the maximum and minimum driver ratings for Prime Sedan bookings.
7. Retrieve all rides where payment was made using UPI.
8. Find the average customer rating for each vehicle type.
9. Calculate the total booking value of successfully completed rides.
10. Identify incomplete rides along with their reasons.

## 📈 Power BI Dashboard

The Power BI dashboard provides an interactive view of:

- Total Bookings
- Successful Bookings
- Cancelled Bookings
- Cancellation Rate
- Customer Cancellation Reasons
- Driver Cancellation Reasons
- Date-wise filtering
- Vehicle and booking insights

## 💡 Key Insights

- The dataset contains 40,539 total bookings, of which 25,207 were successful.
- 11,291 bookings were cancelled, resulting in a cancellation rate of 27.86%.
- Customer and driver cancellations were analyzed separately to identify major cancellation reasons.
- Vehicle types were compared based on average ride distance and customer ratings.
- The analysis identified the top customers based on booking frequency.
- The total booking value of successfully completed rides was calculated to evaluate revenue performance.
